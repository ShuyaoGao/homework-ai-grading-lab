# 现场演示脚本（约 12 分钟）

> 演示用的是**演示数据**：作业图片是程序合成的仿手写图，评分来自离线规则（mock），“教师复核”也是模拟的。
> 页面顶部有紫色的“演示模式”横幅，结果页、画像和看板上有“演示数据”的虚线框。**开场先说明这一点**，不要让看的人以为这是大模型的真实输出。

---

## 0. 演示前 10 分钟：准备

```powershell
cd homework-ai-grading-lab
.venv\Scripts\python -m backend.seed --reset           # 重建演示数据：12 名学生、71 份作业，约 2 分钟
.venv\Scripts\python scripts\make_test_images.py       # 生成现场要上传的照片，放到 samples\generated\
.venv\Scripts\python run.py --host 0.0.0.0 --port 8000 # 启动；终端会打印“手机访问”地址
```

- 浏览器打开 `http://127.0.0.1:8000/`，确认能登录。
- 备用材料：
  - 流程动图 `showcase/assets/flow.gif`，现场网络或设备出问题时直接播放。
  - 展示页 `showcase/index.html`，离线可以直接双击打开。
- mock 处理很快，“识别中/评分中”的进度页通常只闪一下，讲的时候口头提一句即可。

## 1. 让手机连上笔记本（二选一）

**方法 A：真手机（效果最好）**

1. 手机和笔记本连**同一个 WiFi**（同一网段；访客网络或上游路由器的 WiFi 往往和笔记本不通）。
2. 笔记本运行 `ipconfig | findstr IPv4`，记下局域网地址。
3. 手机浏览器打开终端里打印的地址，例如 `http://192.168.1.57:8000/`。
4. 第一次可能弹出 Windows 防火墙提示，选“允许专用网络”。如果没弹出、手机又打不开，在“Windows 安全中心 → 防火墙 → 允许应用通过防火墙”里允许 Python 访问专用网络。
5. 局域网用的是 HTTP，所以“添加到主屏幕”的 PWA 安装不可用（需要 HTTPS），拍照上传不受影响。

**方法 B：Edge 设备模拟（没有手机时）**

- 在 Edge 里按 `F12` 打开开发者工具，再按 `Ctrl+Shift+M` 切到设备模拟，选 iPhone 14 或 390×844。
- 模拟器里点“拍照”会打开文件选择框，从 `samples\generated\` 选图即可。

## 2. 演示顺序与讲解要点

### 第一段：家长（手机，3 分钟）

| 步骤 | 操作 | 讲什么 |
|---|---|---|
| 1 | 登录页点“家长：parent_zhang” | 四种角色共用一套界面，演示账号一键登录 |
| 2 | 首页 | 孩子的同意状态。指出顶部紫色横幅：现在是演示模式，分数不是大模型给的 |
| 3 | 底栏“授权隐私” | 两档同意：基本同意、云端 AI 单独同意。不满 14 周岁的孩子没有同意就不能上传。顺带提一句可以导出数据 |
| 4 | 底栏“拍照上传” → 作业选“语文作文：我心中的英雄” → “拍照”（真手机拍屏幕上的作文图，或在模拟器里选 `samples\generated\zh_essay_photo.png`） | 调后置相机；拍完会**自动弹出裁剪框**，拖四个角去掉桌面，点“左转/右转”演示旋转，再点“完成” |
| 5 | “上传并开始批改” | 有上传进度条；弱网会自动重试（第 4 节有现场演示办法）。几秒后跳到结果页 |
| 6 | 结果页 | 总分、档次、评语、“建议人工复核”的原因；往下是作业图片（可切换处理后/原图）、识别文字中的错误高亮（点一下看说明）、分项得分、扣分项 |

> 注意：用 `samples\generated\` 里的 **PNG** 演示，mock 才能“识别”出文字（图里嵌了标准文本）。用真手机拍屏幕或拍纸质作业时，mock 认不出内容，会返回示例文字，并提示“不是真实识别结果”。这正好可以用来说明演示模式和真实模型的区别。

### 第二段：老师（电脑，4 分钟）

| 步骤 | 操作 | 讲什么 |
|---|---|---|
| 1 | 换浏览器窗口（或无痕窗口），登录“教师：teacher_wang” | 首页：待复核数量、AI 建议重点复核的数量、班级学生与授权状态 |
| 2 | 点“待复核”，打开刚才家长上传的那份 | 队列按时间排列，AI 拿不准的标红“建议复核” |
| 3 | 结果页往下到“教师复核” | 原图和识别文字左右对照；每个分项都显示 AI 给的分 |
| 4 | 把“发展等级”加 2 分，改评语，在“修改理由”里写“引用名言、事例典型”，点“确认并发布” | 每次保存追加一条复核记录，AI 原分保留，用于计算一致性 |
| 5 | （可选）在“修正识别文字”里改一个字，点“保存文字并重新评分” | 识别出错时先改文字；已经复核过的分数不会被覆盖 |
| 6 | 首页 → “班级看板” | 分数分布、各维度得分率、共性问题、多人重复出现的错误（同一个错别字或拼写错误被几个学生写错）、需要关注的学生、AI 与老师的一致性表。**说明一致性数字目前来自模拟复核** |
| 7 | 顶部“量规” → 高考作文 | YAML 量规、发给模型的量规文本；可以复制为自定义量规并校验 |

### 第三段：回到家长和学生（1 分钟）

| 步骤 | 操作 | 讲什么 |
|---|---|---|
| 1 | 回到家长手机，刷新那份作业 | 状态变成“教师已复核”，分数是老师改后的分数；家长看不到 AI 原分和老师的内部备注 |
| 2 | 首页 → “学习画像” | 成绩趋势、写作能力雷达、知识点掌握度、高频错误，都随刚才的复核更新 |
| 3 | （可选）登录“学生：student_zxm” | 学生首页就是自己的画像，只看得到自己的数据 |

### 第四段：管理员与后端（1 分钟）

| 步骤 | 操作 | 讲什么 |
|---|---|---|
| 1 | 登录“管理员：admin” | 模型 provider 状态：只显示 key 是否存在，不显示 key 本身；数据保留清理（先预览再执行）；审计日志 |
| 2 | 打开 `http://127.0.0.1:8000/api/docs` | 41 个接口的交互文档，可以对接其他前端 |

### 第五段：现状与下一步（3 分钟）

- 一致性评估：CFMS-34 上两位人类评分员之间的 QWK 是 0.569，规则基线只有 0.271。规则评分只能用来跑通流程。
- 接入真实模型只需改配置，首轮评估一条命令完成（`scripts/first_real_eval.md`）。

## 3. 可能被问到的问题

| 问题 | 回答要点 |
|---|---|
| 识别准不准？ | 还没测。合成图比真实字迹好认，需要 20–50 份真实作业来测 CER，脚本已经准备好 |
| 会不会把孩子数据发到国外？ | 默认不会。只有监护人单独勾选“云端 AI”才可能发送；推荐用校内服务器上的本地模型 |
| AI 分数会直接计入成绩吗？ | 不会。所有页面都提示“仅供参考”，计入成绩的必须是老师复核后的分数 |
| 一份作业要多少钱？ | 本地模型没有 API 费用。用 Claude Sonnet 5.5 时，按首轮评估的估算，每篇作文的识别加评分大约几美分，以账单为准 |
| 手机没网怎么办？ | 上传会自动重试，离线时等联网后继续；同一批照片不会重复提交 |

## 4. 现场演示弱网重试（可选）

在 Edge 开发者工具的“网络”标签里把限速设为“Offline”，再点上传。页面会显示“当前离线，联网后会自动继续上传”。把限速改回“No throttling”后，上传会自动继续。
